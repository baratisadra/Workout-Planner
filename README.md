# Workout Planner

A Java desktop application that helps users organize and personalize their gym workouts. Users can explore recommended exercises by muscle group, create customized workout plans, and save their progress for future sessions.

## Features

- **Exercise Library:** Browse recommended exercises organized by muscle group.
- **Personalized Workouts:** Select exercises from the library and add them to a personal workout list.
- **Custom Exercises:** Create exercises by specifying their names and muscle groups.
- **Workout Management:** View and remove exercises from the current workout.
- **Save and Load:** Save workout plans to a file and reload them in future sessions.
- **Graphical User Interface:** Interact with the application through a Java-based desktop interface.

## Technologies Used

- Java
- Java Swing (GUI)
- JSON-based persistence

## How to Use

1. Launch the Workout Planner application.
2. Select **View Recommended Exercises** to browse exercises by muscle group.
3. Choose an exercise and click **Add Selected Exercise** to include it in your workout.
4. Use **Add Custom Exercises** to create your own exercises.
5. Select **View My Workout** to review your workout plan.
6. Remove unwanted exercises using **Remove Exercise**.
7. Click **Save My Workout** to save your plan, or **Load My Workout** to restore a previously saved plan.

## Project Motivation

I developed Workout Planner to address a challenge I experienced personally: walking into the gym without a clear workout plan.
I wanted to create an application that would make workout planning more organized and convenient while strengthening my practical Java programming skills.
Through this project, I gained experience designing application logic, organizing code using object-oriented programming principles, developing a graphical user interface, and implementing data persistence.
