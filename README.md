# My Personal Project

## Workout Planner

- The **Workout Planner** is a Java application meant to help users plan 
  workouts for each muscle group. When entering the app, the users can choose 
  the body part they're intending to train, then view the recommended exercices
  shown from the excercise library. The users then can add their chosen exercises
  to their personal exercise list, where they can view their chose exercises, add costumized exercises, and remove any exercise they don't want.
- The **Workout Planner** is built for all those who are seeking a simple way to 
  **organize** their workouts, so they can have a much smoother experience in the gym.
- I decided to build the **Workout Planner** as I too, had experienced times when
  I had a lot going on, and was looking for a way to have a clear mind of what I'm doing when I walk in the gym. Therefore, building this application not only is a practice of my java programming skills, but it also gives me the joy of designing something that solves a problem I once had in my life.

## User Stories

- As a user, I want to be able to add a recommended exercise to my personal exercise list.
- As a user, I want to be able to view the exercises in my personal exercise list.
- As a user, I want to be able to view recommended exercises for my chosen muscle group.
- As a user, I want to be able to remove an exercise from my personal exercise list.
- As a user, I want to be able to save my personal exercise list to file.
- As a user, I want to be able to reload my personal exercise list when I open the application at another time if I wanted to.

## Instructions for End User

- You can view the panel that displays the exercises in the personal workout by clicking the
  "view my workout" button .
- You can generate the first required action that is adding exercises to the workout list
  by clicking "View Recommended Exercises", selecting the preferred muscle group, selecting
  the chosen exercise and clicking "Add Selected Exercise".
- You can generate the second required action by clicking "Add custom exercises", choosing
  the muscle group, entering the exercise name, and clicking "Add exercise".
- You can generate the third required action by selecting an exercise in you exercise list, 
  and clicking the "Remove exercise" button.
- You can locate the visual component on the welcome screen.
- You can save the state of the personal workout list by clicking the "Save my workout" 
  button.
- You can load the state of the personal workout list by clicking the "Load my workout" 
  button.
